# WispFlow Career OS ⚡
**Autonomous Career Intelligence & Real-Time Voice Simulation Platform**

Built for the hackathon with a focus on minimalist design, voice-first intelligence, and empirical skill gap analysis.

---

## 🌟 Overview & Problem Statement

Tech hiring has become an opaque "black box":
- Candidates submit hundreds of resumes with zero actionable feedback.
- Generic roadmaps prescribe 40-hour video tutorials without addressing actual market requirements.
- Standard portfolio projects (to-do apps, clones) fail to impress senior hiring managers.
- Candidates receive no structured, objective interview feedback.

**WispFlow Career OS** closes this loop by analyzing empirical job descriptions, generating a dynamic 6-week learning sprint, architecting high-leverage portfolio projects, simulating voice mock interviews scored against a 4-pillar rubric, and analyzing real-world application outcomes with resume A/B testing.

---

## 🚀 Live Prototype Quickstart

The application is fully built, compiled, and runnable:

```bash
# Clone the repository
cd WispFlow

# Install dependencies (if not already installed)
npm install

# Start the optimized production server
npm run build
npm run start

# Or start the local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 💡 Elite Engineering Differentiators

1. **🎙️ Post-Interview Voice Autopsy (Wispr Flow Enabled):**  
   After a real interview, speak for 60 seconds about questions that challenged you. The system extracts the missed technical concept, logs it under that company in the CRM, and injects a 48-hour remedial sprint into the roadmap.
2. **🧠 Semantic Skill Ontology Graph (DAG):**  
   Replaces naive string matching with an ontological Directed Acyclic Graph with prerequisite chains and transitive inference.
3. **📄 Resume A/B Variant Testing Engine:**  
   Compare callback rates across different resume versions (e.g., *Distributed Systems Focus* @ 42.8% vs. *Full-Stack Focus* @ 11.1%).
4. **🎨 Minimalist Obsidian Dark Mode:**  
   Ultra-sleek Linear/Raycast design language with high signal-to-noise ratio, zero visual clutter, and responsive micro-interactions.
